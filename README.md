# Customer Segmentation

An end-to-end Machine Learning project that uses unsupervised learning to segment customers into groups based on their characteristics and behavior.

The project explores clustering techniques, evaluates different clustering approaches, and integrates the selected model into a usable application.

## Project Overview

The main goal of this project is to discover meaningful customer segments without using predefined labels.

I explored customer data, prepared the features for clustering, and experimented with different unsupervised learning algorithms.

The main clustering approaches used were:

- K-Means
- DBSCAN

The models were compared using clustering evaluation metrics to determine the most suitable approach.
